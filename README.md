# Farm Dash – Living Farm 2.0
3D-Farming-Tycoon im Browser (Three.js), komplett in einer HTML-Datei.

**Spielen:** `index.html` im Browser öffnen (Internet nötig für Three.js).
**Steuerung:** WASD / Pfeiltasten oder auf dem Handy ziehen (Joystick). Ernten, Füttern, Abgeben und Freischalten passieren beim Darüberlaufen.
